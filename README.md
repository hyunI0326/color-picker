# 컬러 픽

화면에서 선택한 색상의 HEX 코드를 이 기기에 저장하는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `color-picker` 폴더를 선택합니다.
4. 도구 모음의 확장 프로그램 메뉴에서 **컬러 픽**을 고정하면 편리합니다.

## 사용

1. 확장 프로그램 아이콘을 눌러 컬러 픽 창을 엽니다.
2. **화면에서 색상 선택하기**를 누르고 원하는 위치를 클릭합니다. 선택을 취소하려면 `Esc`를 누릅니다.
3. 선택한 색상은 자동으로 저장됩니다. 저장 목록에서 코드를 복사하거나 삭제할 수 있습니다. 같은 색을 다시 선택하면 목록 맨 위로 이동합니다.

스포이드는 화면의 픽셀 색상을 선택하므로 웹페이지 외의 화면도 선택할 수 있습니다. 저장된 색상은 이 기기의 Chrome 확장 프로그램 저장소에 보관되며, 확장 프로그램을 제거하면 삭제됩니다.
